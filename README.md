# ระบบเช็คชื่อเข้าเรียนของนักเรียน

ระบบเว็บสำหรับครูที่ปรึกษาใช้เช็คชื่อนักเรียนผ่านมือถือ แนบภาพถ่ายหลักฐาน
ส่งสรุปเข้ากลุ่ม LINE ผู้ปกครองอัตโนมัติ และให้นักเรียนตรวจสอบสถิติการมาเรียนของตนเองได้

เขียนด้วย **PHP 8 + MySQL** ล้วน ไม่ต้องติดตั้งโปรแกรมเสริม ไม่ต้อง build
อัปโหลดขึ้น hosting แล้วใช้งานได้ทันที

## 1. ความสามารถของระบบ

### ฝั่งนักเรียน / ผู้ปกครอง (ไม่ต้องสมัครสมาชิก)
- เข้าดูข้อมูลด้วย **รหัสนักเรียน** อย่างเดียว (เปิดโหมดยืนยันเพิ่มด้วยเบอร์ผู้ปกครองได้)
- เห็นจำนวนวันที่ตนเอง **มาเรียน / มาสาย / ลา / ขาด** และร้อยละการมาเรียน
- เห็น **ภาพรวมทั้งห้อง** ตลอดภาคเรียน พร้อมตารางเปรียบเทียบเพื่อนร่วมห้อง (แถวของตนเองไฮไลต์ไว้)
- เห็น **ภาพถ่ายที่ครูถ่ายไว้** หลังเช็คชื่อในแต่ละวัน
- ดูประวัติรายวันย้อนหลังได้ทั้งเทอม

### ฝั่งครูที่ปรึกษา / ผู้ดูแลระบบ
- ระบบ **เข้าสู่ระบบ / ออกจากระบบ** พร้อมจำกัดจำนวนครั้งที่กรอกรหัสผิด
- **นำเข้ารายชื่อนักเรียนจาก CSV** (รองรับไฟล์ที่บันทึกจาก Excel ภาษาไทย)
- **เช็คชื่อด้วยการแตะปุ่มเดียว** บันทึกทันทีโดยไม่ต้องกดปุ่ม Save
  4 สถานะ: มาเรียน / มาสาย / ลา / ขาดเรียน
- ปุ่มลัด **"ที่เหลือ = มาเรียนทั้งหมด"** เช็คทั้งห้องได้ใน 2 คลิก
- **อัปโหลดภาพถ่าย** ประจำวัน เปิดกล้องถ่ายได้เลยจากมือถือ ระบบย่อรูปให้อัตโนมัติ
- **สถิติ** ภาพรวมทั้งเทอม + แยกรายสัปดาห์ + รายบุคคล + รายชื่อที่ควรติดตามเป็นพิเศษ
- **ส่งออกรายงาน** เป็น Excel (.xlsx 3 ชีต) และ PDF (มีช่องลงนามครูและผู้อำนวยการ)
- **ส่งสรุปเข้ากลุ่ม LINE ผู้ปกครอง** พร้อมยอดมา/สาย/ลา/ขาด รายชื่อ และภาพถ่าย
- รองรับหลายห้องเรียนและหลายครู (ครูเห็นเฉพาะห้องตนเอง ผู้ดูแลเห็นทุกห้อง)

### การออกแบบหน้าจอ
ออกแบบให้ใช้บนมือถือเป็นหลัก ปุ่มขนาดใหญ่แตะง่าย เมนูอยู่ด้านล่างจอในระยะที่นิ้วโป้งเอื้อมถึง
ใช้สีสื่อความหมายชัดเจน (เขียว=มา, ส้ม=สาย, น้ำเงิน=ลา, แดง=ขาด) และมีแถบสรุปที่เติมสีให้เห็นความคืบหน้าแบบทันที

## 2. สิ่งที่เซิร์ฟเวอร์ต้องมี

| รายการ | ขั้นต่ำ | หมายเหตุ |
|---|---|---|
| PHP | 8.0 ขึ้นไป | แนะนำ 8.1–8.3 |
| MySQL / MariaDB | 5.7 / 10.3 ขึ้นไป | ต้องรองรับ utf8mb4 |
| ส่วนขยาย pdo_mysql | จำเป็น | เชื่อมต่อฐานข้อมูล |
| ส่วนขยาย mbstring | จำเป็น | ประมวลผลภาษาไทย |
| ส่วนขยาย curl | จำเป็นถ้าใช้ LINE | ส่งข้อความ |
| ส่วนขยาย gd | แนะนำ | ย่อรูป (ถ้าไม่มีจะเก็บรูปต้นฉบับแทน) |
| ส่วนขยาย zip | แนะนำ | สร้างไฟล์ Excel |
| HTTPS (SSL) | แนะนำอย่างยิ่ง | **LINE จะแนบรูปได้ก็ต่อเมื่อเว็บเป็น https** |

> hosting ในไทยแทบทุกเจ้ามีครบอยู่แล้ว หน้า `install.php` จะตรวจให้อัตโนมัติ

## 3. ติดตั้งบน hosting (cPanel / DirectAdmin)

### ขั้นที่ 1 — สร้างฐานข้อมูล

1. เข้า cPanel → **MySQL Databases**
2. สร้างฐานข้อมูลใหม่ เช่น `attendance`
   (ระบบจะตั้งชื่อจริงเป็น `ชื่อผู้ใช้cPanel_attendance` เช่น `school_attendance` — **จำชื่อเต็มนี้ไว้**)
3. สร้าง MySQL User ใหม่ พร้อมรหัสผ่าน
4. ที่หัวข้อ **Add User To Database** เลือก user + database แล้วให้สิทธิ์ **ALL PRIVILEGES**

### ขั้นที่ 2 — อัปโหลดไฟล์

1. เข้า **File Manager** ไปที่ `public_html`
2. สร้างโฟลเดอร์ชื่อ `attendance` (หรือจะวางที่ root เลยก็ได้)
3. อัปโหลดไฟล์ `attendance.zip` เข้าไป แล้วกด **Extract**
4. ตรวจว่าโครงสร้างเป็นแบบนี้

```
public_html/attendance/
├── index.php
├── install.php
├── webhook.php
├── admin/
├── assets/
├── config/
├── includes/
├── samples/
├── sql/
└── uploads/
```

### ขั้นที่ 3 — ตั้งค่าไฟล์ config

1. เข้าโฟลเดอร์ `config/`
2. คัดลอกไฟล์ `config.sample.php` → เปลี่ยนชื่อสำเนาเป็น **`config.php`**
3. คลิกขวาที่ `config.php` → **Edit** แล้วแก้ 3 ส่วนนี้

```php
/* 1) ฐานข้อมูล — ใส่ชื่อเต็มที่ cPanel สร้างให้ */
define('DB_HOST', 'localhost');
define('DB_NAME', 'school_attendance');   // ชื่อฐานข้อมูลเต็ม
define('DB_USER', 'school_attuser');      // ชื่อ user เต็ม
define('DB_PASS', 'รหัสผ่านที่ตั้งไว้');

/* 2) URL ของระบบ — ห้ามมี / ปิดท้าย */
define('BASE_URL', 'https://school.ac.th/attendance');

/* 3) ชื่อโรงเรียน */
define('SCHOOL_NAME', 'โรงเรียนบ้านหนองแวง');
```

> **สำคัญ:** `BASE_URL` ต้องตรงกับที่อยู่จริงเป๊ะ ๆ ถ้าใส่ผิด รูปภาพจะไม่ขึ้นและปุ่มต่าง ๆ จะพาไปผิดหน้า

### ขั้นที่ 4 — ตั้งสิทธิ์โฟลเดอร์ uploads

คลิกขวาที่โฟลเดอร์ `uploads` → **Change Permissions** → ตั้งเป็น **755**
(ถ้าอัปโหลดรูปไม่ได้ ให้ลอง 775 หรือ 777)

### ขั้นที่ 5 — เปิดหน้าติดตั้ง

เปิดเบราว์เซอร์ไปที่ `https://school.ac.th/attendance/install.php`

หน้าจอจะแสดงผลตรวจความพร้อมของเซิร์ฟเวอร์ ถ้าผ่านครบให้กรอก

- ชื่อ-นามสกุลครูที่ปรึกษา
- ชื่อผู้ใช้และรหัสผ่านสำหรับเข้าระบบ
- ชื่อห้องเรียน ปีการศึกษา ภาคเรียน วันเปิด–ปิดเทอม

แล้วกด **ติดตั้งระบบ**

### ขั้นที่ 6 — ลบไฟล์ install.php

> **ต้องทำ** เมื่อเห็นข้อความ "ติดตั้งเรียบร้อยแล้ว" ให้กลับไปที่ File Manager
> แล้ว **ลบไฟล์ `install.php` ทิ้งทันที** มิฉะนั้นคนอื่นอาจใช้ไฟล์นี้สร้างบัญชีผู้ดูแลได้

เสร็จแล้ว เข้าใช้งานได้ที่

- ครู: `https://school.ac.th/attendance/admin/login.php`
- นักเรียน: `https://school.ac.th/attendance/`

## 4. ติดตั้งบน VPS

สำหรับผู้ที่ใช้ VPS (Ubuntu 22.04 / 24.04)

```bash
# 1) ติดตั้งซอฟต์แวร์
sudo apt update
sudo apt install -y nginx mariadb-server php-fpm php-mysql php-mbstring php-gd php-zip php-curl unzip

# 2) สร้างฐานข้อมูล
sudo mysql -e "CREATE DATABASE attendance CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
sudo mysql -e "CREATE USER 'attuser'@'localhost' IDENTIFIED BY 'รหัสผ่านที่ปลอดภัย';"
sudo mysql -e "GRANT ALL ON attendance.* TO 'attuser'@'localhost'; FLUSH PRIVILEGES;"

# 3) วางไฟล์
sudo mkdir -p /var/www/attendance
sudo unzip attendance.zip -d /var/www/attendance
sudo chown -R www-data:www-data /var/www/attendance
sudo chmod -R 755 /var/www/attendance/uploads

# 4) ตั้งค่า config
cd /var/www/attendance/config
sudo cp config.sample.php config.php
sudo nano config.php
```

ตั้งค่า nginx ที่ `/etc/nginx/sites-available/attendance`

```nginx
server {
    listen 80;
    server_name school.ac.th;
    root /var/www/attendance;
    index index.php;

    client_max_body_size 20M;          # รองรับรูปจากมือถือ

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.3-fpm.sock;
    }

    # ปิดกั้นโฟลเดอร์ที่ไม่ควรเข้าถึงจากภายนอก
    location ~ ^/(config|includes|sql)/ { deny all; return 404; }

    # ห้ามรันสคริปต์ในโฟลเดอร์รูป
    location ~ ^/uploads/.*\.(php|phtml)$ { deny all; return 404; }
}
```

```bash
sudo ln -s /etc/nginx/sites-available/attendance /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 5) ติดตั้ง SSL ฟรี (จำเป็นถ้าจะส่งรูปเข้า LINE)
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d school.ac.th
```

จากนั้นเปิด `https://school.ac.th/install.php` แล้วทำตามขั้นที่ 5–6 ข้างบน

## 5. นำเข้ารายชื่อนักเรียนจาก CSV

### รูปแบบไฟล์

ไฟล์ตัวอย่างอยู่ที่ `samples/students_sample.csv` (ดาวน์โหลดได้จากในระบบ)

```csv
เลขที่,รหัสนักเรียน,คำนำหน้า,ชื่อ,นามสกุล,เบอร์ผู้ปกครอง
1,25001,ด.ช.,กิตติพงษ์,แสงทอง,0812345671
2,25002,ด.ช.,ณัฐวุฒิ,ใจดีมาก,0812345672
3,25003,ด.ญ.,ปาริชาต,ทองสุข,0812345673
```

**ระบบยืดหยุ่นเรื่องหัวตารางมาก** — ชื่อคอลัมน์ต่อไปนี้ใช้แทนกันได้

| ข้อมูล | ชื่อคอลัมน์ที่รองรับ |
|---|---|
| เลขที่ | `เลขที่`, `ลำดับ`, `no`, `number` |
| รหัสนักเรียน | `รหัสนักเรียน`, `รหัส`, `รหัสประจำตัว`, `student_code`, `id` |
| คำนำหน้า | `คำนำหน้า`, `prefix`, `title` |
| ชื่อ | `ชื่อ`, `firstname`, `name` |
| นามสกุล | `นามสกุล`, `สกุล`, `lastname` |
| ชื่อ-นามสกุลรวมกัน | `ชื่อ-นามสกุล`, `fullname` (ระบบแยกให้เอง) |
| เบอร์ผู้ปกครอง | `เบอร์ผู้ปกครอง`, `เบอร์โทร`, `phone`, `tel` |

สิ่งที่ระบบจัดการให้อัตโนมัติ

- ไฟล์ที่บันทึกจาก Excel ภาษาไทย (TIS-620/Windows-874) และ UTF-8 อ่านได้ทั้งคู่
- ถ้าไม่มีหัวตาราง จะอ่านตามลำดับ: เลขที่, รหัส, คำนำหน้า, ชื่อ, นามสกุล, เบอร์
- ถ้าไม่ใส่รหัสนักเรียน ระบบสร้างให้เอง (S0001, S0002, …)
- แถวว่างถูกข้ามอัตโนมัติ

### วิธีเตรียมไฟล์จาก Excel

1. เปิดไฟล์รายชื่อใน Excel
2. **File → Save As** → เลือกชนิด **CSV UTF-8 (Comma delimited) (*.csv)**
3. ถ้าเครื่องมีแต่ตัวเลือก `CSV (Comma delimited)` ธรรมดาก็ใช้ได้ ระบบแปลงให้เอง

### วิธีนำเข้า

1. เข้าเมนู **นักเรียน** → หัวข้อ "นำเข้ารายชื่อจากไฟล์ CSV"
2. เลือกไฟล์
3. ถ้าต้องการล้างรายชื่อเดิม ให้ติ๊ก **"ล้างรายชื่อเดิมก่อนนำเข้า"**
   (ระบบจะแค่ซ่อนรายชื่อเดิม ประวัติการเช็คชื่อยังอยู่ครบ)
4. กด **นำเข้ารายชื่อ** ระบบจะรายงานว่าเพิ่มใหม่กี่คน อัปเดตกี่คน

> นำเข้าไฟล์เดิมซ้ำได้ ระบบจะอัปเดตข้อมูลของคนที่รหัสซ้ำแทนการสร้างซ้ำ

## 6. การใช้งานประจำวันของครู

ขั้นตอนทั้งหมดใช้เวลาไม่เกิน 2 นาที

### 1) เช็คชื่อ

เข้าเมนู **เช็คชื่อ** ระบบเปิดวันที่ปัจจุบันให้อัตโนมัติ

- แตะปุ่ม **มา / สาย / ลา / ขาด** ท้ายชื่อนักเรียนแต่ละคน — บันทึกทันทีไม่ต้องกด Save
- แถบด้านบนจะเติมสีและนับยอดให้เห็นแบบเรียลไทม์
- **เคล็ดลับ:** แตะเฉพาะคนที่ ขาด/ลา/สาย ก่อน แล้วกดปุ่ม **"ที่เหลือ = มาเรียนทั้งหมด"** ทีเดียวจบ
- ช่องค้นหาด้านบนพิมพ์ชื่อหรือเลขที่เพื่อหาคนที่ต้องการได้
- แก้ไขย้อนหลังได้ กดลูกศร `‹ ›` หรือเลือกวันที่จากปฏิทิน

### 2) แนบภาพถ่าย

กดปุ่ม **แนบรูป** หรือเข้าเมนู **รูปภาพ**

- กด "เลือกรูป" บนมือถือจะเปิดกล้องให้ถ่ายได้ทันที
- เลือกได้หลายรูปพร้อมกัน
- ใส่คำอธิบายได้ เช่น "เข้าแถวหน้าเสาธง"

## 7. ตั้งค่า LINE ให้ส่งเข้ากลุ่มผู้ปกครอง

> **หมายเหตุสำคัญ:** LINE Notify ปิดให้บริการไปแล้วเมื่อ 31 มีนาคม 2568
> ระบบนี้จึงใช้ **LINE Messaging API** ซึ่งเป็นวิธีที่ LINE รองรับในปัจจุบัน
> ใช้ฟรีในโควตาข้อความพื้นฐาน (แผน Free ส่งได้ 200–500 ข้อความ/เดือน ขึ้นกับประเทศ)
> การส่ง 1 ครั้งพร้อมรูป 2 รูป = 3 ข้อความ ควรประเมินโควตาให้เหมาะกับจำนวนห้อง

### ขั้นที่ 1 — สร้าง Channel

1. เข้า https://developers.line.biz/console/ แล้วล็อกอินด้วยบัญชี LINE
2. สร้าง **Provider** ใหม่ (ใส่ชื่อโรงเรียนได้เลย)
3. ในนั้นสร้าง **Channel** เลือกชนิด **Messaging API**
4. กรอกข้อมูล: ชื่อ Channel (เช่น "ระบบเช็คชื่อ ม.4/1"), หมวดหมู่ = การศึกษา

### ขั้นที่ 2 — เอา Channel access token

1. เข้า Channel ที่สร้าง → แท็บ **Messaging API**
2. เลื่อนลงสุดหา **Channel access token (long-lived)** กด **Issue**
3. คัดลอกโค้ดยาว ๆ ที่ได้
4. เปิดไฟล์ `config/config.php` วางลงในบรรทัดนี้

```php
define('LINE_CHANNEL_ACCESS_TOKEN', 'วางโค้ดยาว ๆ ที่คัดลอกมาตรงนี้');
```

5. กลับไปแท็บ **Basic settings** คัดลอก **Channel secret** มาวางที่

```php
define('LINE_CHANNEL_SECRET', 'วาง channel secret ตรงนี้');
```

### ขั้นที่ 3 — ปิดระบบตอบกลับอัตโนมัติ

ในแท็บ **Messaging API** เลื่อนหา **LINE Official Account features**

- **Auto-reply messages** → ตั้งเป็น **Disabled**
- **Greeting messages** → ตั้งเป็น **Disabled**
- **Allow bot to join group chats** → ตั้งเป็น **Enabled** ← สำคัญมาก

(บางค่าต้องกดลิงก์ไปตั้งที่หน้า LINE Official Account Manager)

### ขั้นที่ 4 — ตั้ง Webhook (เพื่อดึง Group ID อัตโนมัติ)

1. แท็บ **Messaging API** → หัวข้อ **Webhook settings**
2. ช่อง **Webhook URL** ใส่

```
https://school.ac.th/attendance/webhook.php
```

3. กด **Update** แล้วกด **Verify** ควรขึ้น Success
4. เปิดสวิตช์ **Use webhook** เป็นเปิด

### ขั้นที่ 5 — เชิญบอทเข้ากลุ่มผู้ปกครอง

1. แท็บ **Messaging API** → ส่วนบนมี **QR code** ของบอท
2. ให้ครูสแกน QR เพื่อเพิ่มบอทเป็นเพื่อน
3. เปิดกลุ่ม LINE ผู้ปกครอง → **เชิญ** → เลือกบอทที่เพิ่งเพิ่มเป็นเพื่อน
4. เมื่อบอทเข้ากลุ่ม จะทักทายและแจ้ง Group ID ให้ทันที

### ขั้นที่ 6 — ผูก Group ID กับห้องเรียน

**วิธีที่ 1 (อัตโนมัติ)** ถ้าระบบมีห้องเรียนที่ยังไม่ได้ผูก LINE อยู่เพียงห้องเดียว
ระบบจะผูกให้เองทันทีที่บอทเข้ากลุ่ม

**วิธีที่ 2 (พิมพ์ขอ)** พิมพ์คำว่า `id` ในกลุ่ม บอทจะตอบ Group ID กลับมา
คัดลอกไปวางที่ เมนู **ตั้งค่า** → ช่อง **LINE Group ID** → กด **บันทึกการตั้งค่า**

**วิธีที่ 3 (เลือกจากรายการ)** ในหน้าตั้งค่าจะมีกล่องแสดง Group ID ที่ระบบตรวจพบล่าสุดให้คัดลอก

### ขั้นที่ 7 — ทดสอบ

เมนู **ตั้งค่า** → กดปุ่ม **ส่งข้อความทดสอบ**
ถ้าขึ้น "ส่งข้อความทดสอบเข้ากลุ่ม LINE สำเร็จ" และเห็นข้อความในกลุ่ม แปลว่าใช้ได้แล้ว

### หลายห้องเรียน

ถ้าโรงเรียนมีหลายห้อง แต่ละห้องผูก Group ID ของตัวเองได้
โดยใช้ Channel เดียวกัน — เชิญบอทตัวเดิมเข้าทุกกลุ่ม แล้วตั้ง Group ID แยกในหน้าตั้งค่าของแต่ละห้อง

## 10. ความปลอดภัยและการสำรองข้อมูล

### สิ่งที่ระบบทำให้แล้ว

- รหัสผ่านเก็บแบบเข้ารหัส (bcrypt) ไม่มีการเก็บรหัสผ่านจริง
- ทุกคำสั่งฐานข้อมูลใช้ Prepared Statement ป้องกัน SQL Injection
- ทุกฟอร์มมี CSRF token ป้องกันการปลอมคำสั่ง
- ทุกข้อความที่แสดงผลผ่าน escape ป้องกัน XSS
- กรอกรหัสผ่านผิด 5 ครั้ง ต้องรอ 1 นาที
- ครูที่ปรึกษาเข้าถึงได้เฉพาะห้องของตัวเอง (ตรวจสอบทั้งฝั่งหน้าเว็บและ API)
- ไฟล์ `.htaccess` ปิดกั้นโฟลเดอร์ `config`, `includes`, `sql` และห้ามรันสคริปต์ในโฟลเดอร์ `uploads`

### สิ่งที่ผู้ดูแลต้องทำ

1. **ลบ `install.php` หลังติดตั้งเสร็จ**
2. ติดตั้ง SSL (https) — ฟรีด้วย Let's Encrypt
3. ตั้งรหัสผ่านที่คาดเดายาก และเปลี่ยนเป็นระยะที่เมนูตั้งค่า
4. ไม่แชร์บัญชีผู้ดูแลให้คนอื่น — สร้างบัญชีครูแยกให้แต่ละคน

### สำรองข้อมูล

ควรทำอย่างน้อยเดือนละครั้ง หรือทุกสิ้นเทอม

```bash
# สำรองฐานข้อมูล
mysqldump -u attuser -p attendance > backup_$(date +%F).sql

# สำรองรูปภาพ
tar -czf uploads_$(date +%F).tar.gz /var/www/attendance/uploads
```

บน cPanel ใช้เมนู **Backup Wizard** → Download a MySQL Database Backup
และดาวน์โหลดโฟลเดอร์ `uploads` ผ่าน File Manager

### ขึ้นเทอมใหม่

1. เมนู **ตั้งค่า** → เพิ่มห้องเรียนใหม่ ระบุปีการศึกษา/ภาคเรียน/วันเปิด-ปิดเทอม
2. เมนู **นักเรียน** → เลือกห้องใหม่ → นำเข้า CSV รายชื่อ
3. ข้อมูลเทอมเก่ายังอยู่ครบ เรียกดูย้อนหลังได้จากหน้ารายงาน

## 11. แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| **"ยังไม่ได้ตั้งค่าระบบ"** | ยังไม่ได้สร้างไฟล์ `config/config.php` — คัดลอกจาก `config.sample.php` |
| **"เชื่อมต่อฐานข้อมูลไม่สำเร็จ"** | ตรวจ DB_NAME/DB_USER ให้เป็น **ชื่อเต็ม** ที่ cPanel สร้าง (มี prefix นำหน้า) และตรวจว่าให้สิทธิ์ user กับ database แล้ว |
| **หน้าเว็บขาวเปล่า** | PHP มีข้อผิดพลาด — เปิดดู error log ใน cPanel หรือเพิ่ม `ini_set('display_errors',1);` ชั่วคราวที่บรรทัดแรกของ `includes/bootstrap.php` |
| **หน้าเว็บไม่มีสี ไม่มีรูปแบบ** | `BASE_URL` ผิด — ต้องตรงกับ URL จริง และ**ห้ามมี `/` ปิดท้าย** |
| **ภาษาไทยเป็น `????`** | ฐานข้อมูลไม่ใช่ utf8mb4 — สั่ง `ALTER DATABASE attendance CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;` |
| **นำเข้า CSV แล้วภาษาไทยเพี้ยน** | บันทึกไฟล์ใหม่เป็น **CSV UTF-8** จาก Excel |
| **อัปโหลดรูปไม่ได้** | สิทธิ์โฟลเดอร์ `uploads` ไม่พอ → ตั้งเป็น 755 หรือ 775 |
| **รูปใหญ่เกินอัปโหลดไม่ผ่าน** | เพิ่มค่าใน php.ini: `upload_max_filesize = 20M` และ `post_max_size = 25M` |
| **LINE: "Channel access token ไม่ถูกต้อง"** | token ผิดหรือหมดอายุ — ออก token ใหม่แบบ long-lived |
| **LINE: "ข้อมูลที่ส่งไม่ถูกต้อง"** | Group ID ผิด หรือ `BASE_URL` ไม่ใช่ https (รูปจะส่งไม่ได้) |
| **LINE ส่งข้อความได้แต่ไม่มีรูป** | เว็บยังเป็น http — LINE บังคับให้ URL รูปเป็น https เท่านั้น ให้ติดตั้ง SSL |
| **LINE: "เชื่อมต่อ LINE ไม่ได้"** | hosting ปิด cURL หรือปิดการเชื่อมต่อออกภายนอก ติดต่อผู้ให้บริการ |
| **Webhook Verify ไม่ผ่าน** | URL ต้องเป็น https และเข้าถึงได้จากภายนอก ตรวจว่าใส่ Channel secret ใน config แล้ว |
| **สร้างไฟล์ Excel ไม่ได้** | เซิร์ฟเวอร์ไม่มีส่วนขยาย zip — ติดต่อ hosting ให้เปิด `php-zip` |
| **เช็คชื่อแล้วขึ้น "เซสชันหมดอายุ"** | เปิดหน้าเว็บค้างไว้นานเกินไป — รีเฟรชหน้าแล้วเช็คใหม่ |

| `attendance_records` | ผลการเช็คชื่อรายคน |
| `day_photos` | ภาพถ่ายประจำวัน |
| `settings` | ค่าตั้งค่าทั่วไป |
| `line_logs` | บันทึกการส่ง LINE ไว้ตรวจสอบย้อนหลัง |

### ปรับแต่งเพิ่มเติมได้ที่ `config/config.php`

## การทดสอบที่ผ่านแล้ว

ระบบผ่านการทดสอบบน PHP 8.3 + MariaDB 10.11 ครอบคลุม

- ติดตั้งระบบ สร้างตาราง สร้างบัญชีผู้ดูแล
- เข้าสู่ระบบ ออกจากระบบ จำกัดการเดารหัสผ่าน
- นำเข้า CSV ภาษาไทย ตรวจข้อมูลในฐานข้อมูลถูกต้อง
- เช็คชื่อผ่าน AJAX ทั้ง 4 สถานะ นับยอดสรุปถูกต้อง
- ป้องกัน CSRF ปลอม, เข้าถึงห้องที่ไม่มีสิทธิ์, สถานะปลอม, เข้าหน้าโดยไม่ล็อกอิน
- คำนวณสถิติรายเทอมและรายสัปดาห์ถูกต้อง (ตรวจสอบด้วยการคำนวณมือ)
- ส่งออก Excel เปิดด้วย openpyxl ได้ครบ 3 ชีต ภาษาไทยไม่เพี้ยน
- ส่งออก PDF แสดงตารางและช่องลงนามครบ
- อัปโหลดรูป 3000×2000 ย่อเหลือ 1600×1067 และสร้าง thumbnail 480×320
- ข้อความ LINE จัดรูปแบบถูกต้อง และแปลข้อผิดพลาดเป็นภาษาไทย
